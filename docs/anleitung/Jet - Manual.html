Jet

Display for turbines · Manual · Version 0.5.2 · 21 Nov 2026

Jet is a display (a «widget») for FrSky radios running Ethos. On a full screen it shows RPM, exhaust gas temperature (EGT), fuel, ECU battery and the state of your turbine as text, plus fuel flow, pump, thrust, altitude, speed and signal. It watches the values in two stages, reports a shutdown with its reason, announces alarms and the fuel level and keeps a list of your runs. The pictures in this manual show the German display except where noted; the English display uses the same layout.

Test status: Checked with the random test and in the Ethos simulator 26.2 (X18RS): full screen 800 × 480 directly, 640 × 360, 480 × 320 and 480 × 272 as well as the compact view 784 × 316, 630 × 258 and 472 × 210 simulated. Radio test on a real X18RS with simulated JetCat telemetry passed (version 0.1.5, same code in 0.1.6: display, status, shutdown with reason with SF «on» and «off», EGT alarm, announcements «Turbine off», «Flameout», «Turbine running», «EGT high»). Not yet on a radio: announce switch with several parts, English announcements, vibration, turbines 2–4, Xicoy and SportECU. Never tested with a real turbine ECU, only with simulated telemetry. Installing through FrSky Suite has not been tried yet.
Still to be checked on a radio: whether the RPM is right without conversion (setting «RPM times»), whether Ethos creates the Xicoy sensors by itself, the Physical IDs of JetCat turbines 2 to 4, and whether negative status codes arrive correctly through the sensor «Temp2». The Lua-Studio settings file (new in 0.2.0) passed a radio test on an X18RS with 0.2.1 (loading, full view with 16 places, sensor places, broken file). Not yet on a radio: file too new, changes on the radio and «Back», compact view and English with a Studio file, a self-made view. The symbols (Studio format 2, new in 0.3.0) passed the radio test on an X18RS (symbols, bold units, shutdown, EGT alarm); still open: load with very many symbols and decorations, missing symbol image. The English status texts are the manufacturers' original texts. The voice files are only partly checked on a radio; if one is missing, you hear a tone for «Turbine running», «Turbine off» and (with «Tone on alarm») the shutdown reason, otherwise nothing; an alarm always gives a beep. Jet needs about 144 KB of Lua memory, with a Studio file (measured in the simulator) about 100–115 KB more. When you switch to a model without Jet, Jet frees its memory down to about 5 KB (from 0.5.2, measured in the simulator).

1. What you need

  • A FrSky radio with Ethos 26.2 and a colour display (list at the end).
  • A turbine with telemetry to the radio, through one of these: JetCat with its own telemetry adapter (turbine 1 to 4), Xicoy with TeleX adapter, SportECU (e.g. ProJET Hornet III), VSpeak ECU converter (for Kingtech, Swiwin, PBS, evoJet, Hornet/Behotec, Jakadofsky, JetCat). Other turbines work with the setting «manual».
  • The model's sensors already discovered (Model › Telemetry › Discover sensors).
  • Your tank size in ml, the type and cell count of your ECU battery.
  • A computer with FrSky Suite and a USB cable.
  • The file Jet-0.5.2.zip. It is inside Jet-0.5.2-share.zip. Unzip only the outer ZIP, not the inner one.

2. Install

  1. Switch the radio on and connect it to the computer with the USB cable.
  2. The radio shows a choice. Select Ethos Suite.
  3. Open FrSky Suite on the computer. The radio appears at the top.
  4. Click Lua library, then Install from local ZIP.
  5. Select Jet-0.5.2.zip. The Suite copies everything to the right place.
  6. Unplug the cable and restart the radio.

Without the Suite: connect the radio as «USB storage» and copy the folder jet from the ZIP into scripts. If your radio loads scripts from the SD card (System › General › Storage location), it belongs in scripts on the SD card. Overwrite an existing folder, do not delete it.

3. Set up the screen

  1. Tap the Screens icon at the bottom (two rectangles).
  2. Tap + at the top right.
  3. Swipe down to the layout Full screen (one large field) and tap it. To keep the Ethos top and bottom bars, choose the layout with one field and the bars instead (bottom centre of the layout grid); Jet then shows the compact view (chapter 5).
  4. Tap the empty field, then Widget.
  5. Select Jet in the list. The display appears at once.

You reach the widget menu any time through Model › Screens › select the screen › tap the widget.

4. Assign sensors

  1. Switch on receiver and ECU so that telemetry runs. The first time, Jet looks for the sensors by itself; a short blue note «… sensors assigned automatically» appears at the bottom.
  2. Open the menu. At the top, Detected shows the manufacturer Jet recognised from the sensors, e.g. «JetCat». If it says «nothing yet», open the group Manufacturer and select it under Manufacturer yourself.
  3. VSpeak converter only: in the group Manufacturer, select the turbine behind it under ECU at VSpeak (Kingtech, Swiwin, PBS, evoJet, Hornet/Behotec, Jakadofsky, JetCat). Until then Detected shows «VSpeak - Select manufacturer» and the status only as «Code n».
  4. JetCat, Xicoy and SportECU send part of their values with IDs for which Ethos creates no sensors (JetCat 0x5000–0x53FF, SportECU fuel 0x0A10; for Xicoy 0x4400–0x4406 this is not yet checked on a radio). Jet only accepts values from the turbine's Physical ID. Jet reads these values from the telemetry itself; you do not need to set anything. Their lines in the group Sensors (e.g. Status, Set RPM, Pump) may stay empty.
  5. If other devices with the same IDs are connected to the receiver (e.g. an RPM sensor), tap Reassign next to Reassign turbine values at the top, then YES, REASSIGN. Jet then takes the turbine's sensor (Physical ID 0x1B) for every turbine value, if there is one; signal, altitude and speed stay unless their sensor was deleted. If you used «Delete all sensors» in the model and discovered again, also tap Reassign once: Jet then takes all values from the new sensors.
  6. Open the group Sensors and check every line. Select anything empty or wrong by hand. An empty line is allowed; the field then shows a dash.
  7. With Find sensors (empty only) › Search Jet later fills only the empty lines; your own choice stays.
  8. The group Check assignment shows the chosen sensor of each line with Physical ID and AppID (e.g. «EngState1 P1B / 5004»). If several identical sensors matched, a line below says «n sensors match, chosen: … - please check».
  9. Open the group Turbine and set Tank size, ECU battery type and ECU battery cells.

Compact view

If you choose the layout with top and bottom bars (chapter 3), Jet notices this and shows a compact view: a narrow bar at the top with run time, pills and signal (model name and radio battery are in the Ethos header), below it the four gauges and eight fields: STATUS, field 1 to 6 and RUNS. Tapping RUNS opens the run list. Everything else works as in full screen.

Compact view on X20 and X18RS (784 × 316). On X14 and X18 / Twin X Lite it is smaller.

Warning: header and value orange
Alarm: red header, red frame, tone and announcement

A warning or alarm starts when the value has been beyond the limit for 1 second and ends when it has been fine again for 3 seconds. An alarm beeps («Tone on alarm»), announces the value («Announce alarms») and repeats this every 10 seconds («Repeat alarm every») as long as it lasts. A warning is announced only if «Announce warnings too» is on. There are always at least 3 seconds between two announcements. Without telemetry there are no warnings.

Alarm also with turbine off

By default all warnings and alarms also come when «Turbine off at» (default SF↑) is in the off position. In the menu group Alarm also with turbine off you can change this per value (EGT, fuel, ECU battery, receiver battery, RSSI, altitude, speed); all at the top switches all ticks at once. Without the tick this value stays silent while the switch is off: no tone, no announcement, no vibration, the top bar stays calm. The value itself still turns orange or red. If you switch back on and the value is still beyond its limit, the alarm comes at once. ECU error codes and shutdown reasons (e.g. «Flameout») always come, they cannot be deselected.

Contradicting sources

If Jet reads a value directly from the ECU telemetry (JetCat, Xicoy, SportECU) and the sensor set for this value in the menu shows something clearly different at the same time, Jet shows a warning: orange top bar and at the bottom a hint such as «EGT: ECU data and sensor disagree» (again every 30 seconds). This applies to EGT (more than 50 °C or 15 %), RPM (more than 5000 rpm or 15 %), ECU battery (more than 0.5 V) and fuel (more than 10 %), once the difference lasts 3 seconds. Jet keeps showing the ECU value. Then check the assignment (menu › Check assignment), for example if a separate temperature sensor is assigned as EGT. No tone, no announcement.

Fuel in steps

When the fuel drops below 75, 50, 30, 10 and 5 %, the radio says «Fuel» and the number in percent, once each. At 10 and 5 % it also vibrates if «Vibration on alarm» is on. If you refuel and the value rises 5 % above a step, that step counts again. Switch off with «Fuel in steps».

Shutdown

If the ECU reports an error code when the turbine stops (e.g. «Low temp. Off»), or a running turbine stops while «Turbine off at» (default SF↑) is not on and the ECU itself does not report «off», this counts as a shutdown. An error code always counts, even if SF is already «off»: red header, pill SHUTDOWN, STATUS red with the ECU's text. The radio says «Turbine off» and about a second later the reason: «Flameout», «Out of fuel», «Battery low», «Overtemperature», «Failsafe» or otherwise «Fault». For turbines 2 to 4 it says «Turbine two off» and so on. Vibration follows the setting; a tone comes here only if there is no voice file. This announcement always comes, even if «Announce alarms» is off. Without a status sensor or without a known status text, a flameout is when the RPM stays below «Idle from» for 2 seconds. The display stays red until the turbine starts again; SF does not clear it. If you flip SF only after the flameout, it still counts as a shutdown. Limit alarms (EGT, fuel, batteries, signal) also come with SF «off», unless you remove the tick «Alarm also with turbine off» for a value (see above).

Finding the Studio layout (from 0.5.2)

  • Places: Jet searches the Studio file in SCRIPTS:/studio/, SD:/scripts/studio/ and RADIO:/scripts/studio/.
  • Any name: if the file name does not match the model name, choose the file in the widget menu under «Studio layout» (list with the place in brackets). «automatic (model name)» takes ModelName.jet.lua as before. The menu choice wins.
  • Any window size: without a view for exactly this size, Jet scales the most similar view and shows «Studio: view 800x480 adapted» for 5 seconds. Slots that get too small are shown as a number or left out.
  • Hint line: if Jet shows the default display although there is a file, the reason is shown in the header (instead of the model name), e.g. «Studio: file faulty (…)» or «Studio: no matching view».

7. Operation

Detecting runs

A run starts as soon as the turbine turns: the ECU reports a start or running status, or, without a status sensor (or without a known status text), the RPM is above 1000. The run time at the top runs. When the turbine reaches «running» (green; without a status sensor: RPM from «Idle from», default 10000), the radio says «Turbine running». When you switch it off with «Turbine off at», it says «Turbine off» (both only if «Turbine running/off» is on).

When the turbine has stood still for 5 seconds (RPM below 1000, no start or running status), the run ends and goes into the run list without a question. A run counts only from 30 seconds («Run counts from»); shorter runs, e.g. a failed start, are dropped.

Start: pill START, status blue
Tap STATUS: last status changes

Last status changes

Tap the field STATUS. «LAST STATUS CHANGES» opens with the last 5 changes, each with the run time, newest at the top. CLOSE or one turn of the rotary encoder closes the window.

Turbines (page 2)

Only with 2 to 4 turbines: swipe left. One column per turbine with RPM, EGT, fuel, ECU battery and status. Values beyond the warning are orange, beyond the alarm red.

Run list

Swipe left (twice with several turbines) or tap «n runs». The runs are on the right, newest at the top, the current one blue with «running». The column «End» shows «SF off», «Shutdown» (red) or «-». Tap a run: on the left you see Run time, Fuel used, Max. EGT, Max. RPM, Fuel at end, Max. altitude, Max. speed, Lowest ECU batt, End (after a shutdown with the ECU's text) and Turbines.

  1. Delete one run: tap the run, DELETE RUN n, then YES, DELETE. «Run n deleted» appears at the bottom. Later numbers move up.
  2. Delete all runs: CLEAR LIST, then YES, DELETE. «Run list cleared» appears at the bottom. The counter starts again at 1.
  3. CANCEL leaves everything as it is.
  4. Back to the display: < BACK or swipe right.

The list keeps the last 20 runs and stays when you switch off. A run that was still open when you switched off goes into the list the next time you switch on.

End a run by hand

In the menu at the top, tap End next to End run. «End run?» appears with «It goes into the run list.». YES, END ends it and «Run ended» appears at the bottom. A new run starts only after the turbine has stood still once.

Announcement on a switch

When you switch SG↓ on («Announce at»), the radio says «Fuel» with %, «Run time» with minutes and, if switched on, «Altitude» with metres. You choose what is announced in the group Announcements.

Radios without touch (X14, X10, X12)

The rotary encoder pages from the display to the Turbines page and to the run list. On the run list it selects runs; turning back before the first run returns to the display. At the top of the menu there are End run, Delete run (first choose the number at «Run no. to delete») and Delete whole list, each with a confirmation.

Lua-Studio (settings file per model)

With the PC program Lua-Studio you design the display per model: for each field you choose the value, the style (number, ring, horizontal or vertical bar, trend, status), title, range, colours and an extra line (MIN, MAX or Ø over the run). From version 0.3.0 (Studio format 2) there are symbols too (e.g. turbine, impeller, tank, pump, temperature, battery), a bold unit and decoration (lines, frames). The symbols are images in scripts/studio/symbole/; if one is missing, Jet shows the place without it and reports «symbols missing». Files in the old format 1 still load. Settings and limits per model come on top. Lua-Studio creates the file scripts/studio/modelname.jet.lua on the SD card. The file name keeps only the letters A–Z and digits of the model name, everything else becomes _ («Jet 1» becomes Jet_1); Lua-Studio works this out itself. Jet reads the file when the model is loaded.

  • Without this file Jet works exactly as before, with no message.
  • By default the view in Lua-Studio looks like Jet without a file: in full screen four gauges, STATUS and six fields (RUNS stays fixed at the bottom left and opens the run list), in the compact view four gauges, STATUS and seven fields including RUNS. Jet always draws the top bar itself.
  • With a file its view applies only to the window size it was made for (e.g. full screen 800 × 480 or with bars 784 × 316), and in full screen only on page 1. For other sizes Jet draws its built-in display.
  • Safety stays fixed: the file cannot change the shutdown logic. «Turbine off» with its reason comes also with SF «off», the top bar stays red until the turbine runs again, and limit alarms also apply with SF «off». Only per limit may the file deselect this (beiMotorAus = false, in Lua-Studio the tick «also with motor off»); in the menu it is called «Alarm also with turbine off». Error codes and shutdown reasons always come.
  • Limits apply per value, whether and however it is shown. If a value is missing in the file, the factory limit applies. A limit is only switched off if the file says so explicitly (aus = true). If the direction does not fit the value, the factory limit applies as well, with a message. Limits also work for other sensors, channels or non-monitored values, at most 6 per model (limits on missing sensors count too); Jet drops further ones with a message.
  • If you change tank, limits or other settings in the menu on the radio, Jet writes this to its own file …jet.funke.lua. The Lua-Studio file stays unchanged. Lua-Studio shows the differences and takes them over if you want.
  • Menu › Studio file › Reset: with a file «Back to Studio settings» (your changes on the radio are deleted), without a file «Back to defaults» (factory settings and limits; sensors and runs stay). Both ask first.
  • Messages: if the file is broken, too new or contains invalid entries, a hint shows in the header for 8 seconds (e.g. «Studio file broken - default»), then an orange «!» at the top right. Jet always keeps running, if in doubt with its built-in display.
  • Jet also writes the file …jet.info.json with model name, radio, window sizes and sensor list. Only Lua-Studio reads it.

10. Update and remove

Update: Install the new ZIP exactly as in chapter 2. Your settings, sensors, runs and counters stay.

Remove: First take the widget off the screen (Model › Screens), then uninstall it in FrSky Suite under Lua library. The Lua-Studio files are in scripts/studio and can be deleted there by hand.
